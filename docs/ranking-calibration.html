Explicit policy

Sort by unchanged task retrieval score first; only ties use popularity. Finally use candidate ID for deterministic ties. Constraints and semantic suitability still require the calling agent’s review.

Freshness halves every seven days. Ignore future/invalid dates; Trending older than 14 days contributes nothing. Use the most recent usable weekly observation, otherwise most recent daily/monthly; daily gain ×7, monthly gain ×7/30. These are rate approximations, not invented measured weekly totals. Never sum overlapping periods or compare language-filter ranks with global ranks. Unknown/invalid counts contribute no growth. A 100-star denominator offset damps tiny-base ratios. All constants are provisional product policy, not fitted statistical estimates.

This corrects scale and observation age; it does not detect purchased stars, measure software quality, establish acceleration from a time series, or prove better task outcomes. The semantic relevance gate remains lexical retrieval, not validated semantic judgment. Obtain independent task labels and temporal holdouts before tuning coefficients or claiming recommendation lift.
