Reproduction

Run from the repository root. Set SNAPSHOT to the exported catalog used in this report. Its SHA-256 is a6edb4028c33dd7144c39419b957a71b8c56d64824cfb0d1753cea1a3d8c4c6e. Python and the tokenizer are only used by the benchmark.

scratch=$(mktemp -d)
git archive c3a40bd4782b2098b5c85cf72b7077b1e071fa85 skills/hot-pick \
  | tar -xf - -C "$scratch"
python3 -m venv "$scratch/venv"
"$scratch/venv/bin/python" -m pip install tiktoken==0.14.0
TIKTOKEN_CACHE_DIR="$scratch/tokenizer-cache" \
  node benchmarks/token-catalog.mjs "$SNAPSHOT" \
  "$scratch/skills/hot-pick/scripts/hot-pick.mjs" "$scratch/venv/bin/python"
