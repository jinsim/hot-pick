Apply an open-source phonetic feature dataset

This example follows a real catalog coverage miss into general GitHub discovery, source inspection, pinned acquisition, actual application and verification. It uses PanPhon (MIT) data, not a fabricated feature table. PanPhon had 342 stars at inspection; no membership in the observed weekly Trending page was found. Suitability was selected over unrelated popularity.

Requires Node.js 22+, Python 3 and Git. Runtime uses Python's standard library and the acquired CSV; no pip packages, model, API key or paid service. The first acquisition requires public GitHub access. No third-party installation hook executes.

# From the hot-pick repository root:
node skills/hot-pick/scripts/hot-pick.mjs catalog-route --file examples/phoneme-features/task.json --catalog-url https://jinsim-hot-pick.web.app/index.json --discover
node skills/hot-pick/scripts/hot-pick.mjs acquire dmort27/panphon --ref a49c242d3307864312a2701055faefa4e548501c --workspace "$PWD/examples/phoneme-features"
node skills/hot-pick/scripts/hot-pick.mjs apply --plan examples/phoneme-features/plan.json

What is verified

The adapter verifies the CSV's Git blob hash, reads 24 source features, compares caller-provided aligned IPA segments, and emits result.json plus an HTML feature comparison. Checks cover affricate/velar, sibilant/dental, aspiration and place contrasts, identical vectors and four invalid-input cases. It rejects unknown symbols and Hangul rather than silently omitting them. The generated files and executable receipt record actual outputs and hashes.

PanPhon's affricate entry uses a tie bar: t͡ɕ. It is not the literal string tɕ. Inputs are explicit IPA arrays, not an inferred transcription. The example does not process recorded speech, infer tongue position, animate anatomy, implement Korean G2P, or establish clinical accuracy. The mismatch fraction is an unweighted categorical feature difference, not pronunciation accuracy. No claimed timing or quality improvement over an unaided agent follows from this small functional test.

Attribution and maintenance

PanPhon is by David R. Mortensen and collaborators; its acquired checkout contains LICENSE.txt and the README's citation instructions. The full dataset is not vendored here. Generated reports identify repository, commit and data blob. Updating the source requires reviewing and updating those pins plus rerunning value checks. Task-specific source checkouts are retained under ignored .hot-pick for reproducibility; no persistent server is started.
